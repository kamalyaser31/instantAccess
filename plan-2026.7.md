Live test in portable NVDA 2026.2 (2026-11-04), all passed:

Tags: SAFE means no runtime behavior changes. RISKY means runtime behavior changes. Apply the SAFE work in one batch first. Then apply the RISKY items one at a time, and run the tests after each one.

Planning, implementation and testing can be split among models by capacity. M1 and M2 suit a smaller model. M3 suits a stronger model, because it touches dialogs, focus and threads.

8. **Placeholders `{date}`, `{time}` and `{clipboard}`.** Done on `feat/2026.7`. Reviewed and corrected on 2026-11-07, not tested live.    - Safety: `{file}`, `{folder}` and `{selection}` follow the same quoting rules as `{clipboard}`. In `.bat` and `.cmd` arguments they are refused, because paths and text can contain `&`, as in a folder named `R&D`.

The existing Test button lets the user hear the result.
   - Docs: a short list of the placeholders in both readmes, and the search example `https://www.google.com/search?q={clipboard}`.
