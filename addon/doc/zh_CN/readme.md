# NVDA instantAccess 插件

*   **作者：** Kamal Yaser
*   **版本：** 2026.7
*   **兼容性：** NVDA 2024.1 及更高版本

您每天可能会打开相同的程序、访问相同的网站，并输入相同的回复。这些事情往往需要按很多次键，而每增加一个快捷键，就多一个需要记住的组合。

instantAccess 为您提供一个专用的快捷键层。按 `NVDA+E`，再按一个自定义按键即可完成操作。这个操作可以只有一步，也可以由一长串步骤组成。

## 它解决什么问题

*   **快捷键太多，难以记忆。** 所有操作都放在 `NVDA+E` 后面，一个按键还可以在不同程序中代表不同功能。
*   **忘记了快捷键。** 打开项目列表，输入关键词查找，然后按 `Enter`。此列表默认关闭，需要在设置中启用项目浏览。
*   **重复执行相同步骤。** 一个项目可以打开文件夹、启动程序、等待一段时间，再打开网站。
*   **在不同位置复制文本。** 项目可以使用所选文本、剪贴板文本或所选文件。例如，用一个按键搜索当前选中的文字。
*   **没有现成快捷键的操作。** 项目可以代替您按键，例如打开菜单并向下移动五次。

## 安装

1.  在 NVDA 中打开 **工具**，然后选择 **插件商店**。
2.  在可用插件中找到 instantAccess 并安装。
3.  重新启动 NVDA。

您也可以从[发布页面](https://github.com/kamalyaser31/instantAccess/releases)下载插件，打开下载的文件，然后重新启动 NVDA。

## 创建第一个项目

整个过程大约需要两分钟。我们将创建一个在按下 `NVDA+E`，然后按 `N` 时打开记事本的项目。

1.  按 `NVDA+N`，打开 **选项**，然后选择 **设置**。
2.  在类别列表中选择 **instantAccess**。
3.  按 **添加**按钮，打开新对话框。
4.  在 **名称**字段中输入 `打开记事本`。
5.  在此对话框中按 **添加**按钮添加一个操作，打开另一个对话框。
6.  在 **类型**列表中选择 **程序**。
7.  在 **路径或网址**字段中输入 `notepad`，然后按 **确定**。
8.  按 **快捷键**按钮，然后按 `N`。
9.  按 **确定**关闭项目对话框，再按 **确定**关闭设置。
10. 按 `NVDA+E`，然后按 `N`。记事本就会打开。

这就是 instantAccess 的基本用法。一个**项目**包含名称、按键以及一个或多个**操作**。要添加更多步骤，只需编辑项目并添加操作，它们会按顺序运行。

## 使用项目

*   **`NVDA+E`：** 开启或关闭 instantAccess 模式，然后按项目对应的按键运行它。
*   **`Esc`：** 退出模式，不运行任何项目。
*   没有对应项目的其他按键：插件会提示您，然后退出模式。
*   项目或测试正在运行时按 **`NVDA+E`：** 停止当前运行，并清除等待运行的项目。
*   **`NVDA+Shift+E`：** 朗读当前所在程序的名称。
*   快速连续按两次 **`NVDA+Shift+E`：** 将程序名称复制到剪贴板。

如果想使用其他按键代替 `NVDA+E` 或 `NVDA+Shift+E`，请打开 **选项**，选择 **按键与手势**，然后在 **instantAccess** 类别中修改。

项目会逐一运行，避免剪贴板内容和模拟按键互相干扰。如果快速运行多个项目，后面的项目会排队等待。

## 忘记快捷键时查找项目

此功能默认关闭。要启用它，请在插件设置中勾选 **在 instantAccess 模式中启用项目浏览**。

现在进入 instantAccess 模式：

*   **下光标**或 **`Tab`：** 朗读下一个项目。
*   **上光标**或 **`Shift+Tab`：** 朗读上一个项目。
*   **`Enter`：** 运行最后朗读的项目并退出模式。如果还没有移动到任何项目，按 `Enter` 只会退出模式。
*   **`F1`** 或 **`H`：** 打开项目列表并退出模式。

方向键会循环浏览：到达最后一个项目后会回到第一个项目。

在 `F1` 或 `H` 打开的列表中：

1.  在 **查找**字段中输入关键词。它会搜索项目名称、快捷键、应用名称、操作类型和操作内容，例如网址或文件路径。输入多个关键词时，项目必须同时匹配所有关键词。
2.  按 `Tab` 移到列表，然后使用方向键浏览。
3.  按 `Enter` 运行选中的项目，或按 `Esc` 关闭列表。

列表只显示当前程序中可用的项目，包括全局项目和限制在当前程序中的项目。

项目快捷键优先于浏览按键。如果项目使用 `H` 或 `F1`，对应按键会运行该项目，其余浏览按键仍然可用。

以下两个设置会改变朗读内容：

*   **浏览时的朗读方式：** 先读名称，再读快捷键；先读快捷键，再读名称；或仅读名称。
*   **浏览顺序：** 按设置列表顺序、按名称排序或按快捷键排序。

## 示例

下面八个示例涵盖所有操作类型和所有变量。添加项目时可以照着输入，再根据需要修改名称、路径和按键。

### 搜索所选文本

选中任意程序中的文字，然后用一步操作在 Google 中搜索。

*   **名称：** `搜索所选文本`
*   **快捷键：** `S`
*   **操作：** 类型选择 **网站**，路径或网址填写 `https://www.google.com/search?q={selection}`

如果要搜索复制的文本，请将 `{selection}` 换成 `{clipboard}`。

### 开始工作

用一个按键打开工作文件夹、当天的文件和电子邮箱。

*   **名称：** `开始工作`
*   **快捷键：** `W`
*   **操作间隔：** `2`
*   **操作：**
    1.  类型选择 **文件夹**，路径或网址填写 `C:\Work`
    2.  类型选择 **文件**，路径或网址填写 `C:\Work\plan.docx`
    3.  类型选择 **网站**，路径或网址填写 `https://mail.google.com`

操作间隔会给每个程序留出启动时间。默认勾选 **操作失败时停止执行剩余操作**，因此某一步失败后，后续步骤不会运行。

### 在指定程序中粘贴回复和日期

在指定的程序中粘贴一段准备好的回复，操作完成后恢复之前复制的文本。

*   **名称：** `快速回复`
*   **快捷键：** `R`
*   **仅在指定应用程序中启用此快捷键：** 勾选，并填写 `thunderbird, winword`
*   **操作：** 类型选择 **文本片段**，文本片段操作选择 **粘贴**，输入以下两行：
    1.  `感谢您的来信，我会尽快回复。`
    2.  `发送日期：{date}`

在其他程序中，同一个按键可以运行另一个项目。使用 `NVDA+Shift+E` 获取程序的准确名称。如果在浏览器中写邮件，请填写浏览器名称，例如 `chrome` 或 `msedge`。

### 输入日期和时间

在任何可输入文字的位置，以当前日期和时间开始一段记录。

*   **名称：** `时间戳`
*   **快捷键：** `T`
*   **操作：** 类型选择 **文本片段**，文本片段操作选择 **输入文本**，文本填写 `{date} {time}: `

### 在记事本中打开所选文件

在文件资源管理器中选择文件，然后用记事本打开它，即使该文件默认关联了其他程序。

*   **名称：** `用记事本打开`
*   **快捷键：** `O`
*   **操作：** 类型选择 **程序**，路径或网址填写 `notepad`，参数填写 `{file}`

如果要修改受 Windows 保护的文件，请勾选 **以管理员身份运行**。Windows 会显示通常的权限提示；如果拒绝，插件会提示“已取消”。

### 复制当前文件夹的路径

在文件资源管理器的文件夹中，将完整路径复制下来，以便发送给他人或粘贴到其他位置。

*   **名称：** `复制文件夹路径`
*   **快捷键：** `P`
*   **操作：** 类型选择 **文本片段**，文本片段操作选择 **复制**，文本填写 `{folder}`

### 复制当前行

在文档中无需手动选择，直接复制光标所在的行。

*   **名称：** `复制当前行`
*   **快捷键：** `L`
*   **操作：** 类型选择 **按键序列**，按键间隔填写 `0.1`，并输入以下三行：
    1.  `home`
    2.  `shift+end`
    3.  `ctrl+c`

也可以按 **添加按键**按钮录制按键，而不是手动输入按键名称。

### 打开插件商店

有些 NVDA 命令没有默认快捷键，可以为它们指定一个按键。

*   **名称：** `插件商店`
*   **快捷键：** `A`
*   **操作：** 类型选择 **NVDA 命令**。按 **选择命令**，在查找字段中输入“商店”，然后选择打开插件商店的命令。

## 可配置内容

### 设置面板

从 **选项**、**设置**、**instantAccess** 打开设置面板。列表显示每个项目的名称、类型、快捷键和详细信息。

*   **查找：** 按项目名称缩小列表。使用查找时不能调整顺序。
*   **添加、编辑、删除：** 管理项目。在列表中按 `Enter` 编辑，按 `Delete` 删除。
*   **复制：** 复制项目及其所有操作。副本不会保留快捷键。
*   **测试：** 立即运行选中的项目。如果项目会输入文字、模拟按键、读取所选文本或文件资源管理器中的内容，插件会先询问，然后等待 3 秒，以便切换到目标窗口。
*   在列表中按 **`Ctrl+Up`** 和 **`Ctrl+Down`：** 移动选中的项目，新的顺序会立即保存。
*   **详细程度：** **初级**会朗读完整提示，例如“instantAccess 已开启，已加载 10 个项目”；**高级**使用简短提示音。
*   **运行项目时朗读名称：** 如果不想听到项目名称，可以关闭此选项。每个项目也可以单独设置。

### 项目选项

*   **名称：** 不能与其他项目重复的名称。
*   **操作：** 项目要执行的步骤。可使用 **添加**、**编辑**、**删除**、**上移**和**下移**。在列表中按 `Delete` 删除，按 `Ctrl+Up` 和 `Ctrl+Down` 调整顺序。
*   **操作间隔（秒）：** 每个操作后暂停，最后一个操作除外。
*   **操作失败时停止执行剩余操作：** 默认勾选。取消勾选后，即使某个操作失败，后续操作仍会运行。
*   **运行此项目时朗读名称：** 可选择 **使用常规设置**、**朗读**或**不朗读**。错误始终会被朗读。
*   **启用：** 取消勾选即可停用项目而不删除它。停用的项目不会运行，也不会出现在 instantAccess 模式中，设置列表会标记为“已禁用”。它的快捷键仍会被保留。
*   **仅在指定应用程序中启用此快捷键：** 勾选后，可将项目限制在指定程序中。然后填写 **应用程序名称，以逗号分隔**。如果勾选时字段为空，插件会自动填写打开设置前所在程序的名称。
*   **快捷键：** 按此按钮，然后按一个按键，例如 `G`，或按组合键，例如 `Ctrl+Shift+G`。每个项目都需要快捷键。`Esc`、`NVDA+E` 和 `NVDA+Shift+E` 已被保留，不能使用。

没有应用程序限制的项目是全局项目。如果一个全局项目和一个应用程序专用项目使用相同按键，当前程序中的专用项目优先。

要为项目添加第二个程序，请切换到该程序，快速连续按两次 `NVDA+Shift+E`，然后将程序名称粘贴到字段中，并用逗号分隔。

### 操作类型

*   **网站：** 在默认浏览器中打开网址，也可以打开其他地址，例如用于打开 Windows 蓝牙设置页面的 `ms-settings:bluetooth`，或 `mailto:name@example.com`。
*   **程序：** 启动程序。可以填写完整路径，也可以填写 Windows 已知的名称，例如 `notepad` 或 `cmd`。还可以填写**参数**并勾选**以管理员身份运行**。批处理文件（`.bat` 和 `.cmd`）也可以使用。
*   **文件夹：** 在文件资源管理器中打开文件夹。
*   **文件：** 使用系统为该文件类型设置的默认程序打开文件。
*   **NVDA 命令：** 运行 NVDA 命令。按 **选择命令**，从可查找的列表中选择命令。
*   **文本片段：** 使用自定义文本，支持以下三种方式：
    *   **输入文本：** 模拟按键输入文字。**字符输入间隔（秒）**设置字符之间的暂停时间。
    *   **复制：** 将文本放入剪贴板。
    *   **粘贴：** 先粘贴文本，再将原来的文本恢复到剪贴板。只能恢复文本；如果剪贴板中是图片，或是在文件资源管理器中复制的文件，这些内容会丢失。此时应改用**输入文本**。
*   **按键序列：** 每行按下一个按键或组合键，例如 `alt+f4` 或 `shift+f10`。
    *   要重复按键，请在按键名称后加空格和次数，例如 `down 5`。
    *   以 `#` 开头的行会被跳过，可以用来写备注。
    *   **添加按键：** 按此按钮，然后依次按下要录制的按键，最后按 `Esc` 完成。每个按键会成为新的一行；连续按下多次的按键会合并为一行，例如 `down 3`。单独按下 `Ctrl`、`Alt` 或 `Shift` 也会被记录，并在按下下一个键时朗读。数字小键盘按键使用独立名称，例如 `numpad1`、`numpadEnter` 和 `numpadDivide`；小键盘导航键使用 `numpadHome` 等名称。NVDA 可能会先处理小键盘按键，导致录制器收不到，尤其是在 `Num Lock` 关闭时；此时请手动输入按键名称。`Esc` 用于完成录制，如果需要把它作为按键输入，请手动填写 `esc`。
    *   **按键间隔（秒）：** 两次按键之间的暂停时间。

每个操作还具有：

*   **执行此操作前的等待时间（秒）：** 执行当前操作前的暂停时间。某一步需要更多时间时可以使用，例如启动较慢的程序。
*   **测试：** 不保存项目，单独尝试当前操作。如果会输入文字、模拟按键、读取所选文本或文件资源管理器中的内容，插件会先询问，然后等待 3 秒，以便切换到目标窗口。

### 变量

变量是用花括号括起来的名称，项目运行时会自动替换。变量可用于文本片段、网址和程序参数。按字段旁的 **插入变量**按钮即可选择：

*   **日期（`{date}`）**和**时间（`{time}`）：** 使用 Windows 格式的当前日期和时间。
*   **剪贴板文本（`{clipboard}`）：** 您复制的文本。
*   **所选文本（`{selection}`）：** 项目开始运行时选中的文本。
*   **所选文件（`{file}`）：** 文件资源管理器中选中的文件。选择多个文件时会全部使用。
*   **打开的文件夹（`{folder}`）：** 文件资源管理器当前打开的文件夹。

需要注意：

*   项目需要所选文本、所选文件或打开的文件夹时，如果当前没有这些内容，项目会在执行任何操作前停止并提示原因。
*   文件资源管理器有多个选项卡时，文件或文件夹可能来自另一个选项卡。
*   `{clipboard}`、`{selection}`、`{file}` 和 `{folder}` 不能用于 `.bat` 和 `.cmd` 文件的参数，因为这些文本可能会被当作命令执行。
*   要输入花括号，请将其加倍：`{{` 会生成 `{`，`}}` 会生成 `}`。
*   如果您在旧版本中创建了包含花括号的文本，请检查这些项目。现在 `{date}` 等词会被替换，`{{` 会生成 `{`。

### 参数

参数用于告诉程序启动时要执行什么。可以查看程序帮助页面，或在命令提示符中使用 `--help` 或 `/?` 获取参数。

### 备份和迁移项目

使用 **导出设置**将全部配置保存到文件，使用 **导入设置**加载文件。选择文件后，插件会询问如何处理：

*   **替换：** 文件中的项目和设置替换现有全部配置。
*   **合并：** 只添加名称未占用且快捷键未占用的新项目，保留现有设置。插件会提示添加和跳过的数量。

插件会将项目备份到 `config.json.bak`。如果设置文件损坏，插件会提供恢复备份的选项。

## 出现问题时

1.  重现出现问题的操作。
2.  按 `NVDA+F1` 打开 NVDA 日志。
3.  找到包含 `instantAccess:` 的行并复制。
4.  在 [问题反馈页面](https://github.com/kamalyaser31/instantAccess/issues)发帖，并简短说明您进行了什么操作。

这些日志可能包含项目名称和文件路径，发布前请先检查。

各版本的变化请查看[更新日志](https://github.com/kamalyaser31/instantAccess/blob/main/changelog.md)。
